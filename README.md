# Smart Parking Slot Availability System

A real-time Smart Parking Slot Availability System developed using Arduino, IR sensors, Python, and a web dashboard. The system detects whether parking slots are occupied or empty and displays live parking updates through a webpage.

---

## Features

- Real-time parking slot monitoring
- Live parking status updates
- Web-based dashboard
- Low-cost IoT prototype
- User-friendly interface
- Reduces parking search time and congestion
- Smart parking monitoring using IR sensors

---

---

## Working of the Project

The IR sensors detect whether a parking slot is occupied or empty. The Arduino processes the sensor data and sends it to Python using serial communication. The Python program updates the parking status on the web dashboard in real time.

---

## Important Note

⚠️ This prototype is currently designed to work only with **3 IR sensors (3 parking slots)**.

The system can be extended in the future for larger parking areas using:
- Additional sensors
- AI/ML models
- Camera-based vehicle detection
- Smart parking prediction systems
